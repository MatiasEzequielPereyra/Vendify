## RPC and authorization contract

`listar_negocios_plataforma_v2(p_search text=null,p_plan_codigo text=null,
p_estado text=null,p_limit integer=50,p_cursor jsonb=null)` returns
`{contract_version:1,items:[business],next_cursor:cursor|null}`.

`obtener_negocio_plataforma_v1(p_negocio_id uuid)` returns
`{contract_version:1,business:business|null}`.

Authorization checks auth.uid() and es_admin_plataforma_v1() before business
lookup/filter validation. Commercial roles do not grant global authority.
SECURITY DEFINER permits explicit global projection across RLS without direct
table exposure. Empty search_path, qualified objects, no dynamic SQL, STABLE,
PUBLIC/anon revoked, authenticated EXECUTE only. No new service_role grant.

Projection: business ID/name/created/active; subscription plan/name/state/trial and
limits; active membership/branch counts and all products. Missing subscription
remains null. No credential, personal employee, payment, sales or raw log fields.
The old obtener_plan_actual_v1 is never invoked. No operator context mutation.

Cursor validates shape, filters, fixed order, bounds and exact microseconds.
Ordering is creado DESC,id DESC. The unsigned positional cursor does not convey
authority. Concurrency limits are documented in the read-model document.
